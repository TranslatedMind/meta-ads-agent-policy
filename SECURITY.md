# Reporting a problem

Found a mistake or a safety gap in the instructions? Open a GitHub issue with the affected section, what could go wrong, and a suggested improvement if you have one. Use a small example with made-up data.

Do not include access tokens, credentials, personal information, or client data. If a real credential was exposed, revoke or rotate it rather than posting it here.

This repository contains a community policy template, not a running service. Reports and fixes are handled on a best-effort basis, with no guaranteed response time.
